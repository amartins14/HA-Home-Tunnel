Set up your relay

Pair this app with your IIS relay

Generate one setup code. Add its hash to the relay's web.config, then enter the relay URL to pair.

Keep this code in Home Assistant. Only its hash goes into web.config; the app uses the code to authenticate pairing without sending it.

Caller locations

Optional approximate IP lookup

When enabled, Home Tunnel sends public caller IPs to ipapi.co to estimate their city, region, and country. Results can be inaccurate. Lookups are cached for 24 hours, up to 200 new IPs per day.
